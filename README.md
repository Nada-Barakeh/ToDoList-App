# To-Do List App

Ein einfaches Java-Konsolenprogramm zur Verwaltung täglicher Aufgaben.  
Dieses Projekt dient als Übung für objektorientierte Programmierung, Unit-Tests und Git.

#  Funktionen (Features)
- **Aufgabe hinzufügen:** Neue Aufgaben mit Titel und Beschreibung anlegen.
- **Alle Aufgaben anzeigen:** Eine Liste aller aktuellen Aufgaben ausgeben.
- **Aufgabe als erledigt markieren:** Eine Aufgabe anhand ihrer ID als abgeschlossen markieren.
- **Aufgabe löschen:** Eine Aufgabe anhand ihrer ID entfernen.

# Verwendete Technologien (Technologies)
- **Java 25** (oder die von dir verwendete Version)
- **Gradle** (Build-Management und Abhängigkeiten)
- **JUnit 5** (Unit-Tests zur Qualitätssicherung)

# Ausführen des Projekts (How to Run)
1. Stelle sicher, dass Java und Gradle auf deinem System installiert sind.
2. Öffne das Projekt in IntelliJ IDEA.
3. Führe die `Main.java`-Klasse aus, um das Programm zu starten.

# Tests ausführen (Running Tests)
Um die Unit-Tests auszuführen, nutze folgenden Befehl im Terminal:
./gradlew test

# Projektstruktur (Project Structure)

    src/main/java/model: Enthält die Klasse Task.
    src/main/java/service: Enthält die TaskService-Klasse (Logik).
    src/main/java/org/example: Enthält die Main-Klasse (Benutzeroberfläche).
    src/test/java: Enthält die TaskServiceTest-Klasse (Unit-Tests).
